## Follow-up

Keep the isolated, final-file-only publisher and the user's developer hot reload. No process is killed and no launch flag is changed. Per-file atomic publication cannot guarantee that CK3 accepts every live data-category transition. Start the next acceptance run in a fresh game session so the new story definitions load together; this does not remove hot reload support.

For a recurrence, retain the new bundle and latest autosave, record the in-game date and visible action, and compare whether the same module-relative address repeats. A saved state immediately before the fault is needed for reproduction. Source checks and an error-free build do not prove native crash clearance.
